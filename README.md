# 🍽️ Food Brand: Understand Customer Trends

## 📘 Project Overview
The **Food Brand Project** analyzes customer behavior, sales trends, and brand performance using Power BI. This repository includes dashboards, cleaned datasets, and DAX measures developed as part of my individual contribution.

## 💼 My Contributions
- Created **DAX measures** for Milestones 2, 3, and 4 to calculate key metrics like Avg Rating, Experience Score, Total Reviews, Active Users, and User Persona segmentation.  
- Developed **Power BI dashboards**:
  - Milestone 3: Customer sentiment and activity analysis.  
  - Milestone 4: Customer segmentation based on personas and activity frequency.  
- Prepared and cleaned the dataset used for analysis (`dataset_cleaned.xlsx`).  
- Documented all **DAX measures** in `DAX_Measures_Milestones_2_to_4.docx`.  
- Assisted in preparing the Milestone 2 presentation summarizing insights.

## 📂 Files in this Repository
- **`FoodBrand_Project_Infosys-Milestone2.pbix`** – Power BI file for Milestone 2 dashboards.  
- **`Infosys Milestone 2.pptx`** – Presentation summarizing Milestone 2 findings.  
- **`Infosys_milestone_3.pbix`** – Power BI dashboard for Milestone 3 (customer sentiment and activity).  
- **`Infosys_Milestone_4.pbix`** – Power BI dashboard for Milestone 4 (customer segmentation).  
- **`DAX_Measures_Milestones_2_to_4.docx`** – Document containing all DAX measures I created.  
- **`dataset_cleaned.xlsx`** – Preprocessed dataset ready for analysis.

##  🌟 Key Features
- Interactive dashboards visualizing customer behavior and sales trends.  
- Segmentation and sentiment analysis using custom DAX measures.  
- Ready-to-use cleaned dataset for further exploration.  
- Metrics and KPIs calculated for comprehensive customer insights.

## 🧭 How to Use
1. Open the `.pbix` files in **Power BI Desktop**.  
2. Explore dashboards and reports to analyze trends and insights.  
3. Refer to the `.pptx` file for summarized findings.  
4. Check `DAX_Measures_Milestones_2_to_4.docx` for all the DAX formulas I implemented.
